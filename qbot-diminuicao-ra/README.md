# Q-LAB — Diminuição até o átomo

Arquivos prontos para GitHub Pages.

## Arquivos
- index.html
- qbot_diminuicao_atomo_RA.glb

## Instalação
Envie a pasta `qbot-diminuicao-ra` para a raiz do repositório `qlab-ra`.

Com GitHub Pages ativo no branch `main` e pasta `/ (root)`, a página ficará em:
https://kayaralima-sys.github.io/qlab-ra/qbot-diminuicao-ra/

O QR Code deve apontar para a página acima, e não diretamente para o arquivo GLB.
