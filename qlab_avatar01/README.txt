Q-LAB — AVATAR 01 / RA

ARQUIVOS:
- index.html : visualizador WebAR
- avatar01.png : imagem de referência do avatar
- QR_AVATAR01_EXEMPLO.png : QR de exemplo (trocar após publicar)

FALTA APENAS:
- avatar01.glb : modelo 3D real do personagem

COMO PUBLICAR:
1. Crie no repositório qlab-ra uma pasta chamada avatar01.
2. Coloque index.html e avatar01.glb dentro dela.
3. Ative GitHub Pages para o repositório.
4. A página terá formato semelhante a:
   https://SEU-USUARIO.github.io/qlab-ra/avatar01/
5. Gere o QR Code usando ESSA página, não o endereço /blob/ do arquivo GLB.

IMPORTANTE:
O QR incluído é apenas um modelo porque SEU-USUARIO precisa ser substituído pelo usuário real do GitHub.
